# FreeCut Montage — плейбук

Монтаж видео полностью headless: Claude сам режет/клеит/накладывает графику и звук, рендерит, смотрит на кадры и правит. Пользователь браузер не открывает. Отработано на 82-мин созвоне «ИИ + Программист» (ДВА деливерабла из одного build.mjs: Boosty и @codeonvibes — `DELIVERABLE=boosty|codeonvibes node build.mjs`, различается аутро-CTA).

## 0. ГЛАВНЫЙ УРОК ПРОЦЕССА (не нарушать)

- **Итерируй на ДЕШЁВЫХ чекпоинтах (10-20 сек рендерятся за секунды) → лочи каждый элемент → ОДИН полный рендер в самом конце.** НЕ запускай часовой полный рендер, пока стиль/анимации/дизайн не залочены. Это прямой запрос пользователя.
- **Для решений по движению показывай варианты A/B/C короткими mp4** (пользователь смотрит и выбирает) — стиллы движение не передают.
- **Честно про ограничения и компромиссы** (субтитры мусорят слайды, филлеры резать нельзя, маскот без рига не машет, правый чёрный = зона вебки). Не обещай невозможное.
- **Подтверждай перед дорогими/необратимыми шагами.** Показывай кадр после КАЖДОГО нетривиального изменения (Read PNG).

## 0.5 ОРКЕСТРАЦИЯ: конвейер стадий → агент → МОЙ гейт (до 99.99% готовности)

**Контракт с пользователем:** к нему попадает видео, уже прошедшее ВСЕ гейты и УЖЕ ИСПРАВЛЕННОЕ. Если агент/гейт нашёл дефект — я чиню и перепроверяю, а не пересылаю проблему наверх. Пользователь смотрит финал и подтверждает, а не отлаживает. К нему идёт одна сводка «что было / что стало», а не список нерешённых проблем.

**Ветка ШОРТСЫ:** для вертикального шортса (9:16, ≤60с) стадия 1 (analyst) и пул `transcript-highlight-miner` ОСТАЮТСЯ — пул это обязательный вход `montage-shorts-producer`; он заменяет только scriptwriter/coldopen/CD/memolog/stinger (одна идея, хук за 1с, реФрейм под вертикаль, вшитые субтитры ВКЛ, петля). `montage-asset-sourcer`/`motion-designer` — по применимости (если план шортса требует ассеты/анимацию); `caption-copy-editor` — субтитры и хук-текст; `retention-pacing-critic` — шорт-профиль (хук ≤1-3с; главы/мёртвые зоны/CTA-окно N/A); упаковка — по платформе. Остальные гейты (факты, кадр, continuity-техспек 1080×1920, звук) те же — **вертикальную спеку (1080×1920, 9:16, ≤60с, LUFS платформы) передаю в задачу `montage-continuity-qc` явно**, его дефолты заточены под 16:9-лонг. Part-1 (графсистема) для шортса сокращён: гаттер/акцент/шрифт/safe-zone; бюджет маскота, маркеры глав, разделители, бренд-панель — N/A (их в ≤60с нет по замыслу).

**Жёсткие правила гейтов:**

- **BLOCK/FAIL от `montage-factchecker` или `montage-continuity-qc` — финал НЕ рендерю**, чиню и перепрогоняю гейт.
- Каждый нетривиальный элемент проверяю КАДРОМ после сборки (Read PNG), не «на глаз».
- Дешёвые чекпоинты → лок каждого куска → ОДИН финальный рендер (правило §0). Полный рендер — только после явного «ок» пользователя.
- Дефекты чиню Я до порога. Наверх — готовое + сводка «было/стало», не проблема на разбор.
- **Координаты таймкодов — две системы.** Планировочные агенты (miner/scriptwriter/coldopen/CD/stinger/memolog) работают в координатах ИСХОДНИКА (SRC); QA-агенты (frame/retention/continuity/audio) — в координатах СОБРАННОГО таймлайна (исключение: ранний 3b-прогон retention — по исходнику + running order). Мост — `agents-out/timecode-map.json` (рождается на ст.7): все SRC-данные (AUDIO-GATE, таймкоды планов) конвертирую в таймлайн ПЕРЕД передачей QA-агентам. Каждый отчёт помечает свою систему.
- **Холодный старт канала (бренд-файлов нет):** до ст.6 фиксирую с юзером минимальный voice-spec + бренд-канон (акцент/база/шрифт/tone) файлом в `brand/`; юзер недоступен — дефолт-бренд скилла (Tech-keynote, `#FF7A00`/`#0B0E14`) с пометкой в сдаче. Этот файл передаю всем stop-агентам (copy-editor / continuity-qc / упаковка) — вечный stop не допускается.
- **Composer вернул «материал не даёт хука»:** ре-прогоняю highlight-miner с пониженным порогом / другим срезом (цифры, эмоции, контрасты); повторное «нет хука» — эскалация юзеру с вариантами (тизер из цитат-карточек / выпуск без тизера). Тизер молча не выкидываю.
- **REWORK от scriptwriter/coldopen:** чиню ВХОД (бриф/пул), ре-прогоняю агента; второй REWORK подряд — эскалация юзеру (это структурное суждение, не механический фикс). При слиянии планов в `cue-list.json` дедуплицирую `sfximpact` до ОДНОГО на ролик (CD и stinger оба вправе его поставить).
- **Правка любой экранной СТРОКИ после стадии 6** (по frame-critic, qa-sweep, вкусовая) **ре-триггерит `montage-factchecker` (и `caption-copy-editor`) по изменённым строкам** — иначе их PASS протухает молча.

## 1. Пайплайн (как это работает)

- **Собери project.json руками** (схемы: `src/types/timeline.ts`, `project.ts`, `transform.ts`, `text.ts`, `keyframe.ts`, `motion.ts`, `text-motion.ts`). Формат: items ПЛОСКО в `timeline.items[]` со ссылкой `trackId`; дорожки в `timeline.tracks[]`; анимация в `timeline.keyframes[]` (кадры относительно старта элемента).
- **Рендер:** `node headless/render.mjs --workspace <ws> --project <file.json|id> --in <sec> --duration <sec> --quality high --out out.mp4`. Само-сервит `dist/` (нужен `npm run build` один раз) и range-стримит медиа (рендерит только нужный кусок). `edit.mjs` / `serve.mjs` — см. `headless/README.md`.
- **Проверка = извлечь кадр и ПОСМОТРЕТЬ:** `ffmpeg -y -ss <t> -i out.mp4 -frames:v 1 f.png` → Read f.png. Это основная петля обратной связи (Claude «видит» результат). Для движения — рендерь короткий mp4 и клади в `_previews/`.
- **Трек-порядок:** меньше `order` = выше (ближе к зрителю). Видео внизу (большой order), оверлеи сверху (малый/отрицательный order).
- **⚡ Быстрая петля (session-2, встроено в FreeCut):** `npm run headless:frame -- --workspace <ws> --project <f> --at <sec> --out x.png` — один кадр за ~3с. `npm run headless:layout -- ... --at <sec>` → JSON bbox всех элементов (x,y,w,h,opacity,z) за **89мс БЕЗ рендера** — юзай для проверки координат вместо рендер-итераций. Тёплые `/frame` `/layout` в serve.mjs.
- **⚠️ ОДИН элемент на трек в момент времени:** накладывающиеся по времени items на ОДНОМ треке → рендерится только ОДИН. Каждый одновременный элемент — на СВОЙ трек (карта уже так: kicker/title/sub/bg — разные треки). Это же правило для подписей/стикеров/панели.
- **Текст без прыжков/обрезки:** хелпер `textRect(x,y,w,h,{hAlign,vAlign})` → абсолютный прямоугольник (дефолтный текст-бокс = весь canvas, оттого капризы). Реюзабельные удары: `punch/flash/shake/hit`.
- **Стикеры-реакции = роялти-фри Fluent Emoji (MIT)**, папки **sentence-case** (`Thumbs up`, не `Thumbs Up`; `Speech balloon`). Хелпер `sticker(preset:pop/drop/slide)`. Видео-врезки: `fullScreenClip` (2.7с ЧИСТЫЙ кат, без баннера) + `sideVideoInsert` (3.0с, заезд справа, оранж рамка). Ассеты НЕ генерим — роялти-фри (Fluent/Lucide MIT, Simple Icons CC0 лого, Pexels/Mixkit видео); imagegen юзера скачивается и кладётся в assets.
- **Micro-удар осмысленный:** контекстный ЦВЕТ (красная виньетка на шок/негатив, золотая на деньги) + стинг, БЕЗ зума кадра (вебка/панель не должны прыгать). Не одинаковый эффект на всё — только на панч.
- **⭐ Анимированные оверлеи (Code-on-Vibes Motion Pack) — работают через движок-фикс (session-3).** Пре-рендер-анимации пака (плашки/панели/стат-бейджи/виньетки/energy-wipe/портал) как **VP9/WebM с альфой** + живые H.264-фоны карт композитятся поверх видео. Раньше не работало: occlusion-куллер FreeCut считал full-canvas alpha-video непрозрачным и выкидывал видео под ним. **Пофикшено** (`frame-occlusion.ts` + `canBeTransparent` из mediabunny, см. память [[freecut-headless-editing]]). Грабли: **ProRes 4444 в headless Chrome НЕ декодится** → перегоняй в VP9: `ffmpeg -i in.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 26 -an out.webm` (даёт `alpha_mode=1`); H.264-фоны (непрозрачные) декодятся как есть; анимир. WebP-alpha НЕ композитится. Полный оверлей — full-frame 1920×1080, opacity 1, текст поверх в safe-зоне. Панель-оверлей 4с НЕ замирает на последнем кадре → **гибрид** (оверлей-въезд 4с + статик-PNG на остаток блока). Маскот пака фикс-справа (конфликт с бренд-панелью) → держи текущий PNG+keyframe маскот.

## 2. ГРАБЛИ И РЕШЕНИЯ (главное — не наступать снова)

- **Чёрные полосы снизу/слева.** Исходник созвона 1920×**1030** (НЕ 1080). Canvas 1920×1080. Дефолтный fit + `crop` → чёрный леттербокс. **ФИКС: cover-fill видео** — `transform: { width: 2013, height: 1080, x: 0, y: 0 }` (масштаб до высоты 1080, лёгкий горизонтальный overscan). НЕ используй `crop` для рефрейма — он даёт полосы.
- **Правый чёрный участок** = мёртвая зона рядом/под вебкой в САМОЙ записи (это контент исходника, масштабом не убрать). Слайд «выше» 16:9, поэтому обрезать под контент = срезать ~четверть по высоте (режет заголовок/подвал). **Решение: брендовая панель поверх чёрного справа** (тёмная `#0F1420` + оранжевый акцент + прогресс-точки ●●●○○/тема блока, без @handle), вебку оставить сверху. Координаты подгонять итерацией по кадру.
- **Позиционирование текста капризное.** Текстовый item с `backgroundColor`+`backgroundRadius`+`textPadding` авто-собирает читаемую «пилюлю» (надёжно). Многоэлементные лево-выровненные раскладки (число+подпись в панели) вылезают — только через рендер-итерации. ## 4. Анимация (что умеет FreeCut)

- **Keyframes** (`timeline.keyframes`): свойства `opacity, x, y, width, height, rotation, cornerRadius, crop*, volume`. Easing: `linear|ease-in|ease-out|ease-in-out|hold|cubic-bezier|spring`. Spring: `easingConfig:{type:'spring',spring:{tension,friction,mass}}` — для физики (выезд с отскоком).
- **textMotion** (побуквенно/по словам): In-пресеты `typewriter`(char), `fade-up`(word), `rise`, `cascade`, `pop`, `blur-in`, `slide-mask`, `wave-in`; параметры `unit`, `staggerFrames`, `durationFrames`, `intensity`, `easing`, `order`. Печать: `typewriter` unit `character` staggerFrames 1-2.
- **motionModifiers** (процедурный idle, без кейфреймов): `breath-pulse`, `float-drift`, `sway`, `spin`, `micro-shake` — оживить маскот/элемент (`amplitude` 0-2, `frequency` Гц).
